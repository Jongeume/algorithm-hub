# 🧩 알고리즘 문제 풀이 기록

> 코딩테스트·알고리즘 학습 과정에서 푼 문제들의 기록.
> **LeetCode · 프로그래머스** 풀이가 자동으로 커밋됩니다.

## 이 저장소는

크래프톤 정글 과정에서 알고리즘을 공부하며 푼 문제들을 모읍니다.
**"많이 푸는 것"보다 "어떤 상황에 어떤 자료구조·기법을 쓰는지 이해하는 것"** 에 초점을 둡니다.
그래서 푼 코드는 여기, 개념 정리는 따로 관리합니다.

| 무엇 | 어디 |
|---|---|
| 푼 문제 원본 코드 | **이 저장소** (자동 커밋) |
| 유형별 개념 · 왜 빨라지나 · 틀렸던 지점 | 개인 학습 노트 |
| 정리해서 설명한 글 | [블로그](https://jongeume.github.io) |

## 구성
